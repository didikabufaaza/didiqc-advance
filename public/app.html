Apa itu Ped dan Pfr?

Ped (Probability of Error Detection)
Probabilitas QC mendeteksi error analitik saat benar-benar terjadi. Semakin tinggi Ped, semakinefektif. Target: ≥ 90%.
Pfr (Probability of False Rejection)
Probabilitas QC menolak run yang sebenarnya valid (false alarm). Target: ≤ 5%.
Interpretasi:
• Ped tinggi + Pfr rendah (σ≥4): QC optimal
• Ped sedang + Pfr sedang (3≤σ<4): Perlu multi-rule
• Ped rendah + Pfr tinggi (σ<3): QC tidak reliable

Z-Score PME (Penilaian Eksternal)

Z-Score PME otomatis dihitung Z = (Hasil − Mean Peserta) / SDPA jika dibiarkan kosong. Interpretasi: |Z|≤2 Memuaskan · 2<|Z|<3 Kurang Memuaskan · |Z|≥3 Peringatan.

Rentang Tanggal QC (Z-Score QC)

Menampilkan hasil Z-Score QC dari data Input QC pada rentang tanggal & parameter terpilih. Z = (Nilai QC − Mean Lot) / SD Lot. Rentang ini juga dipakai untuk interpretasi Z-Score QC pada tabel Bias PME.
