🆘 Troubleshooting

❌ Deploy button error 404

Pastikan repo GitHub Anda sudah ada. Ganti USERNAME di URL dengan username GitHub Anda yang sebenarnya.

❌ Build error: "Prisma Client not generated"

Tambahkan ke package.json: "postinstall": "prisma generate"

❌ Database connection failed

Pastikan DATABASE_URL di Vercel env vars formatnya: postgresql://user:pass@host:5432/db?sslmode=require Jika password ada karakter @, encode jadi %40.

❌ Auto-deploy tidak trigger saat git push

Cek di Vercel: Project → Settings → Git → "Connected Git Repository". Pastikan repo GitHub Anda terhubung. Atau pakai GitHub Actions workflow (lihat .github/workflows/deploy-vercel.yml).
